## Smart-Vision-System-using-ESP32-CAM-and-YOLOv8-for-Real-Time-Detection
This project demonstrates a real-time object detection system using **ESP32-CAM / IP Webcam** and the **YOLOv8 model**. It is designed for beginners who want to understand how wireless camera streaming and object detection can be combined with minimal setup.  

The repository contains:

- A Python script for real-time object detection (`det_8`)
- ESP32-CAM / IP Webcam streaming integration
- Sample output images demonstrating detection results
